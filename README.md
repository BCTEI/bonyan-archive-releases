## ⬇️ تحميل أحدث إصدار

**[اضغط هنا لصفحة أحدث إصدار](https://github.com/BCTEI/bonyan-archive-releases/releases/latest)**

اختر الملف المناسب من قسم **Assets** في صفحة الإصدار:

| النظام | الملف | ملاحظات |
|---|---|---|
| Windows | `bonyan-archive-system-<الإصدار>-x64.exe` | **الموصى به** — برنامج تثبيت عادي |
| Windows | `bonyan-archive-system-<الإصدار>-x64.msi` | للتثبيت عبر سياسات المؤسسة |
| Linux (Debian/Ubuntu) | `bonyan-archive-system-<الإصدار>-amd64.deb` | |
| Linux (أي توزيعة) | `bonyan-archive-system-<الإصدار>-x86_64.AppImage` | لا يحتاج تثبيت |

> ⚠️ قد يظهر تحذير **Windows SmartScreen** لأن البرنامج غير موقّع رقمياً بعد.
> اضغط **More info** ثم **Run anyway** للمتابعة.

سجل جميع الإصدارات: [Releases](https://github.com/BCTEI/bonyan-archive-releases/releases)

## ⬇️ Download the latest version

**[Latest release page](https://github.com/BCTEI/bonyan-archive-releases/releases/latest)** — pick a file under **Assets**:

- **Windows:** `…-x64.exe` (recommended installer) or `…-x64.msi` (for managed deployment)
- **Linux:** `…-amd64.deb` (Debian/Ubuntu) or `…-x86_64.AppImage` (any distribution, no install)

Windows SmartScreen may warn because the installers are not yet code-signed — choose **More info → Run anyway**.

This repository contains release downloads only. Source code is private.
